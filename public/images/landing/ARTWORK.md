# Homepage clay artwork

All delivered images were generated/edited with the built-in image_gen tool. PNG alpha was verified before delivery. Encoding resized the accepted output to 1200 × 800 with PNG palette compression; no programmatic background removal was used. Images are served as PNG using unoptimized Image components, with explicit dimensions and lazy loading except the hero.
